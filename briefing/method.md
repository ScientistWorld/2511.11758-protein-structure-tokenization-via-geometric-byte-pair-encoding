# Reference method

The reference directly calls the released PT-BPE GEOBPE implementation (upstream commit 68ff87eaf13068c1ef93dd72139efe4b91532219). It fits empirical histograms, initializes residue medoids, performs global SE(3) glue optimization and quantization, prioritizes geometric adjacent pairs, clusters selected occurrences by RMSD k-medoids, substitutes medoids, and updates the pair map. Held-out encoding replays the learned vocabulary without extending it. This is the paper's algorithm, not the legacy scratch implementation.

Restored paper settings: free bond-length quantization, histogram bins 500, original-geometry reassignment (`rmsd_super_res=True`), global glue optimization every 10 rounds with prior 1, and translation weight 1 as used for the paper's Pareto experiments after Table 17. Medoid counts follow the main Table 14 regime {2:100,3:500,5:20,6:100}. Out-of-range values snap to the nearest end bin, as Appendix K prescribes. Sorting occurrence lists and file paths fixes seeded sampling order.

Resource reductions are 128 fitting chains instead of 33,992, 2,048 clustering candidates instead of 5,000, and 5 merge rounds. The full training corpus and original clustering setting would exceed this iteration's CPU budget; the computational steps and inference regime are preserved. The driver omits plots and intermediate training-score plots, not algorithm steps. Original published results remain unchanged under `_paper_reported`.

`method/train.py` saves resumable checkpoints and exports the finite dictionary. `method/encode.py` applies the frozen official tokenizer and exports only motif and boundary indices. Independent evaluation reconstructs the backbone, charges the complete dictionary and stream, and never reads method-written metric claims. `baseline/internal.py` supplies an independent fixed-bin baseline; `baseline/residue_quantized.py` retains the old baseline's favorable geometry while charging its full continuous output.

The final reference uses the main Table 14 medoid schedule `{2:100,3:500,5:20,6:100}`, rather than the earlier small Table 16 codebook. Five merge rounds follow the paper’s Appendix K.2 compression guidance for a small corpus; this is a resource-scaled operating point, not a claim to match reported Table 16 values. The separate `method/refine.py` audit variant keeps all model floats and motif assignments fixed and performs discrete boundary coordinate descent against the supplied input backbone.
